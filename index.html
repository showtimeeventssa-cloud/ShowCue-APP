ShowCue How-To Manual

Complete guide to setting up, preparing and using ShowCue for live performance.

1. What ShowCue Does

ShowCue is a local performance-control app for singers, musicians, DJs and live entertainers. It keeps your songs, videos, Cue Pads, setlists and lyrics together so you can launch a prepared performance cue quickly from a phone, tablet or computer.

2. Home

The Home screen is the main navigation screen. Use the cards to open Setlists, Songs, Cue Pads, Media, Lyrics, TV Display, Settings, Backup and Help. The five-button mobile navigation bar remains available on phones and tablets: Home, Setlists, Songs, Cue Pads and Lyrics.

EXIT: The Exit button requests that the app/window close. Browser security can prevent a web page from closing its own Safari/Chrome tab. If the browser refuses to close it, use the device's normal Home/app-switcher control.

3. Songs

Open Songs and choose ADD AUDIO TRACK to import audio. ShowCue accepts MP3, AIFF, FLAC, M4A, WAV and WMA files for storage. You can also create a song entry without an audio file. Set the BPM for each song when using Cut Track.

Imported files are stored locally on the device in the ShowCue media database. Playback support still depends on the browser/device codec; on older iPads, MP3, WAV, AIFF and common M4A are the safest choices.

4. Media

Open Media and choose ADD VIDEO to import MP4, M4V, MOV or AVI. A video can be assigned to a Cue Pad. Use the DELETE button next to an individual video to remove only that video.

CLEAR ALL VIDEOS removes every imported video from the Media library and removes those video assignments from Cue Pads. It does not delete your songs.

5. Cue Pads

Cue Pads are the live performance launch buttons. Choose 12, 20 or 40 pads. Press a pad to cue its assigned song. If a video is assigned to the same pad, the video is treated as part of that cue and is synchronized with the audio.

Use the pencil/edit button on a pad to set its name, colour, audio track and video. CLEAR PADS clears all pad assignments, including songs and videos, but does not delete the underlying Songs or Media library files.

The same performance pads also appear on the Lyrics page so you can launch a cue while working with lyrics.

6. Setlists

A Setlist saves the current Cue Pad performance setup so it can be used again. Configure the pads first, then choose SAVE CURRENT PADS AS SETLIST and give it a name. The saved setlist keeps the pad arrangement, names, colours, songs, videos and pad count.

From Setlists you can LOAD INTO CUE PADS, RENAME, UPDATE FROM CURRENT PADS or DELETE a saved show. Loading a setlist restores that show into Cue Pads.

7. Lyrics

Lyrics can be typed or pasted directly into the editor with your device keyboard. Choose IMPORT LYRICS to import lyrics from PDF, DOC or DOCX files. After importing, review the text because document formatting can differ between files.

The Performance Pads below the lyrics use the same Cue Pad assignments. Cues launched from the Lyrics page still send their assigned video to the TV Display when TV Display is enabled; the lyrics/pad control remains on your device.

8. Sync Lyrics To Track

First cue a pad containing the song you want to use. Open Lyrics, make sure the lyrics are loaded, then press SYNC LYRICS TO TRACK. ShowCue links the lyric scroll to the current track position. Use the scroll-speed control to make the lyrics move slower or faster. AUTO SCROLL can be started/stopped, while the manual up/down and reset controls remain available.

9. TV Display

Open TV Display and switch TV Display ON. Then use OPEN TV DISPLAY to open the separate ShowCue display window. When a Cue Pad containing a video is launched, the video can play on the display while its audio plays from the main device.

For a physical TV, use the device's screen mirroring/second-display function or place the ShowCue display window on the second monitor. BACK TO PADS is for returning the local device from the video/display view to the Cue Pads interface; it does not replace the TV Display control.

10. Settings — Level Matching Sync

Level Matching Sync analyses imported audio and raises softer tracks toward the loudest analysed track. It only adds playback gain and does not lower louder tracks. Your original audio files are not changed.

11. Settings — Cut Track

Cut Track detects the beginning of meaningful audio and removes unnecessary silent/noiseless lead-in at playback. The song still starts before the detected first sound so the musical entrance is not chopped.

Set the song's BPM on the Songs page, then choose the desired Lead-In Before Cue:

  • 2 Bars (8 beats) — keeps approximately two musical bars before the detected first sound.
  • 4 Bars (16 beats) — keeps approximately four musical bars before the detected first sound.

If the detected lead-in is shorter than the selected amount, playback starts from the beginning rather than using a negative start time.

12. Backup

Use EXPORT BACKUP to save ShowCue's configuration/data as a backup. Use the import control to restore compatible ShowCue data. Keep a backup before making major changes to your performance setup.

13. Recommended Live-Show Workflow

  1. Import your Songs and set BPM values.
  2. Import your performance videos in Media.
  3. Build your Cue Pads and assign songs/videos.
  4. Choose your pad colours and names.
  5. Enable Level Matching Sync if required.
  6. Enable Cut Track if required and choose 2 or 4 bars.
  7. Enter/import lyrics and test lyric scrolling.
  8. Turn on TV Display and test the external display.
  9. Save the complete setup as a named Setlist.
  10. Use the Cue Pads during the show and keep the device charged and connected to the required display.

14. Important File and Browser Notes

ShowCue stores imported media locally in the browser on the device. Clearing browser/site data, private browsing sessions, storage cleanup or uninstalling the PWA can remove locally stored media/data. Keep backups where appropriate.

Importing a file and being able to play that file are separate things. A browser may accept a WMA or AVI file for storage but still lack the codec required to play it. Always test the exact files and device you intend to use before a live show.

15. Troubleshooting

  • Song will not play: try MP3, WAV, AIFF or common M4A and confirm the file plays in the device browser.
  • Video will not play: use a browser-compatible MP4/M4V/MOV file and test it before the show.
  • TV is not showing the video: open TV Display, switch it ON, then use OPEN TV DISPLAY and test the pad again.
  • Lyrics are not moving correctly: cue the correct song first, then press SYNC LYRICS TO TRACK and adjust scroll speed.
  • Cut Track starts too early/late: check the song BPM and choose 2 or 4 bars as appropriate.
  • Media is missing: check that the browser/device storage was not cleared and restore from a backup if available.

16. Before Every Performance

Test every important Cue Pad, song, video, lyric cue and TV output. Confirm your Setlist is saved, your device is charged, and your external display/mirroring connection is working before the audience arrives.
